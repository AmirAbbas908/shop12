# سایت فروش کفش

یک وب‌سایت فروشگاهی برای نمایش و فروش کفش، ساخته‌شده با **HTML, CSS و JavaScript**.

> توضیح: این پروژه یک وب‌سایت سمت کلاینت (Front-end) برای نمایش محصولات کفش است.

## ✨ ویژگی‌ها

- 👟 نمایش لیست محصولات (کفش‌ها) همراه با تصویر، قیمت و توضیحات
- 🔍 امکان جستجو و فیلتر محصولات (در صورت پیاده‌سازی)
- 🛒 سبد خرید ساده با JavaScript
- 📱 طراحی واکنش‌گرا (Responsive) برای موبایل و دسکتاپ
- 🎨 رابط کاربری با CSS اختصاصی

## 📂 ساختار پروژه

```
shoe-shop/
├── css/          # استایل‌ها
├── js/           # اسکریپت‌ها (منطق سبد خرید، فیلتر و ...)
├── images/       # تصاویر محصولات
├── index.html    # صفحه‌ی اصلی
└── README.md
```

## 🚀 اجرای پروژه

چون این یک پروژه‌ی کاملاً استاتیک است، نیازی به نصب یا سرور خاصی نیست:

```bash
git clone <https://github.com/AmirAbbas908/shop12>
cd shoe-shop
```




و در مرورگر به آدرس زیر بروید:

```
http://127.0.0.1:8000/
```
